# IDLE DEPOT Asset Pack v1.1

Revised visual identity based on the Producer's supplied reference image.

## Art direction
Premium colorful isometric 2.5D container-depot tycoon: detailed dimensional objects, bright industrial environment, blue-roof white buildings, saturated ribbed containers, yellow heavy equipment, friendly uniformed workers and dark navy glossy UI.
